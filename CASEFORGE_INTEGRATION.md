# CaseForge integration changelog

## Added
- Provably Fair for case openings: server commit, client seed, nonce and verification history.
- Daily bonus wheel with rolling 24h cooldown.
- Referral system with referral codes, commissions and payout threshold.
- Promo codes on demo deposits (`WELCOME` is seeded).
- Runtime appearance settings.
- Basic admin analytics endpoint.
- Case battle mode against 2–4 demo bots.
- New UI pages: Bonus, Battles, Referrals, Provably Fair.
- Promo-code field in the demo deposit dialog.

## Important
This remains a demo Express/JSON project. Real payment processing, real Steam inventory deposits and automated market withdrawals are not enabled by this patch.
