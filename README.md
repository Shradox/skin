# SkinBox demo

Node/Express demo: cases, server-side weighted RNG, inventory, upgrade, login and TEST MODE admin odds.

Run: `npm install` then `npm start`.
Demo user: `demo / demo`. Admin: `admin / change-me`.

The supplied Yandex `yabs.yandex.by/count/...` URL is a tracking URL, not a stable price API. Use a legitimate JSON/API feed in `PRICE_SOURCE_URL`.

No real-money payments are included. Odds editing is explicitly test-only and logged.
