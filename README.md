# DmitrashDrop demo

Node/Express demo: cases, server-side weighted RNG, inventory, upgrade, login and TEST MODE admin odds.

Run: `npm install` then `npm start`.
Demo user: `demo / demo`. Admin: `admin / change-me`.

Цены: Skinport API (резерв — market.csgo.com), обновление каждые 10 мин, кэш в `market-cache.json`.
Картинки: Steam CDN (ссылки из ByMykel CSGO-API, резерв — поиск Steam Market). Если API недоступен — берутся цены из data.json и заглушка вместо картинки.
Проверить статус: `GET /api/prices`.

Виртуальный баланс, реальные деньги не используются. Изменение шансов — только тестовый режим, журналируется.

## Steam-вход
Опционален и выключен по умолчанию. Чтобы включить:
1. Разверните сайт на публичном домене с HTTPS.
2. Получите ключ на https://steamcommunity.com/dev/apikey (Steam требует указать домен).
3. В `.env` задайте `STEAM_API_KEY` и `APP_URL=https://ваш-домен`.
4. `npm install` подтянет `passport` и `passport-steam`, перезапустите сервер.
Без ключа кнопка Steam скрыта, доступен только тестовый логин `demo/demo`, `admin/change-me`.
Steam-вход подтверждает только личность (ник, аватар) — реальный инвентарь CS2, торговые ссылки и депозит/вывод скинов не подключены, баланс остаётся демонстрационным.
Это не тестировалось живьём (в среде сборки нет доступа в интернет) — проверьте вход на своём сервере после деплоя.

## Регистрация
`demo/demo` и `admin/change-me` остаются как были. Плюс обычная регистрация логин+пароль (кнопка «Регистрация» в окне входа) — пароли хранятся хешированными (scrypt, без внешних зависимостей). Новый аккаунт получает демо-баланс $1000.

## Страница кейса и мульти-открытие
Клик по кейсу в списке открывает его отдельную страницу (`#case-<id>`): картинка, полный список предметов с шансами, переключатель «Быстрое открытие» (ползунок) и кнопки 1–5 для одновременного открытия нескольких копий кейса. При открытии 2+ кейсов анимация рулетки пропускается — сразу показывается сетка выигранных предметов с кнопкой «Продать всё».

## Контракты
Ограничение по сумме поднято до $100 000 (было $1000).

## Пополнение (демо-крипта)
Кнопка «+ Пополнить» в шапке — выбор монеты (BTC/ETH/USDT/LTC/TON), генерация случайного адреса и кнопка «Я оплатил» — зачисляет сумму на демо-баланс без проверки сети.
**Важно:** это полностью демонстрационная имитация. Адреса генерируются случайно на лету, ничем не отслеживаются и никому не принадлежат — реальные переводы на них будут потеряны безвозвратно. Модалка это явно предупреждает. Для настоящего приёма платежей нужен реальный платёжный провайдер/нода — здесь этого нет и не планировалось.

## Вывод скинов (демо) и уведомления
Кнопка «Вывести» на предмете в инвентаре/профиле имитирует отправку трейда: предмет убирается из инвентаря сразу, а через 4–7 секунд приходит уведомление («примите обмен в Steam», демо). Колокольчик 🔔 в шапке показывает непрочитанные уведомления (депозиты и выводы), всплывающие тосты — сразу при появлении. Реальные Steam-трейды не отправляются.

## Профиль
Клик по имени пользователя в шапке → страница профиля: статистика (кейсов/апгрейдов/контрактов), любимый кейс (по числу открытий), последние дропы, инвентарь с теми же действиями (продать/заменить/апгрейд/вывести).

## Лента дропов и лидерборд
`GET /api/feed` — последние 150 выигрышей (кейсы/контракты/апгрейды), обновляется на странице раз в 5 сек.
`GET /api/leaderboard?period=day|week|all` — топ по сумме потраченного (кейсы+контракты+ставки апгрейда) за период.
`GET /api/stats` — количество кейсов/игроков/открытий/апгрейдов для шапки сайта.


## CaseForge-inspired additions
This DmitrashDrop build keeps the original Express/JSON architecture and adds:
- Provably Fair commit/client-seed/nonce history for case openings.
- Daily bonus wheel with 24-hour cooldown.
- Referral codes, referral commissions and payout threshold.
- Promo code support for demo deposits.
- Runtime appearance/settings endpoint.
- Basic analytics endpoint for the admin.
- Case battles against 2–4 demo bots.
- Fair, Bonus, Battle and Referral sections in the UI.

These are demo implementations. Real-money payments, Steam inventory deposits and automated Steam/market withdrawals still require production integrations and legal/compliance work.
